# Healthcare-Data-Analysis-and-Insights
🏥 Healthcare Data Analysis using Microsoft Excel

📌 ASSIGNMENT OVERVIEW 

This assignment focuses on analysing healthcare data using Microsoft Excel. The objective is to consolidate multiple healthcare datasets, perform data cleaning, analyse patient medical information, and create meaningful visualisations to identify patterns and insights.

The assignment combines customer information, medical examination records, and hospitalisation details into a single consolidated dataset. PivotTables, Excel formulas, and interactive-style dashboard visualisations are used to summarise and present the findings.

🎯 Assignment Objectives

• Consolidate multiple healthcare datasets into one master dataset.
• Perform data cleaning and handle missing values.
• Retrieve and combine data using VLOOKUP.
• Analyse healthcare information using PivotTables.
• Compare cancer history among smokers and non-smokers.
• Examine the relationship between transplant history, major surgeries, and average HbA1C.
• Create charts and a dashboard to communicate insights effectively.
